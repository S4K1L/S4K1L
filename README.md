**Now.** Flutter developer at OrpheusPLC in Dhaka, shipping apps for real users. Dart on the front, Firebase, Supabase or a REST API behind it, BLoC holding the state together, Figma open on the second screen.

**Before.** C and C++ and a desk full of Arduino boards: an RFID attendance and gate system, IoT health and greenhouse monitors, a robo-soccer bot. Hardware taught me that code has to survive the real world, and that habit followed me into mobile.

**Always.** Problem solving. Data structures, algorithms, and OOP that stays honest.
