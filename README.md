## About

**Now.** Software engineer at OrpheusPLC in Dhaka. I build mobile apps in Flutter and the backends behind them in Django and FastAPI, from the first screen to the release.

**Before.** C and C++ and a desk full of Arduino boards: an RFID attendance and gate system, IoT health and greenhouse monitors, a robo-soccer bot. Hardware taught me that code has to survive the real world, and that habit followed me into software.

**Always.** Problem solving. Data structures, algorithms, and OOP that stays honest.

## How I build

State lives in BLoCs, and I reach for Provider or GetX when an app calls for it. The UI sends events, the BLoC owns the logic, and data stays behind a repository that talks to Django, FastAPI, Firebase or Supabase.

<img src="assets/bloc.svg?v=2" alt="BLoC data flow: the UI sends an event to the BLoC, which asks a repository for data and emits a new state back to the UI" width="100%">
